# ClipForge AI

AI-powered professional video clipping and editing app.

## Goal

ClipForge AI analyzes long-form videos using campaign guidelines and identifies the strongest moments for short-form content.

The app will eventually support:

- Long video analysis
- AI clip selection
- AI hook generation
- 3–5 recommended clips
- Automatic subtitles
- Professional subtitle styling
- 9:16 vertical video
- Clip trimming
- Crop and positioning
- Font customization
- Text color
- Subtitle animation
- Video quality selection
- Local video rendering
- MP4 export
- Save directly to Android storage

## Architecture

Android App
→ AI Analysis
→ Clip Recommendations
→ Local Video Editor
→ Local Rendering
→ MP4 Export
